# Alias for statsServer

Backward compatible wrapper around \[statsServer()\].

## Usage

``` r
statsServer2(id, registryName, ...)
```

## Arguments

- id:

  Character string shiny module id

- registryName:

  Character string registry name key

- ...:

  Arguments passed directly to \[statsServer()\].

## Value

Same result as \[statsServer()\].
